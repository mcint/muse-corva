Muse Corva is Loren and Claude's collaboration to build a GitHub App bot, so that when Claude works on Loren's repos it shows up as itself, muse-corva[bot], and not wearing Loren's name.

WHAT IT IS

A GitHub App is GitHub's way of giving software its own identity: its own name, badge and permissions, separate from any person. Muse Corva is the mask Claude wears on GitHub. When a Claude Code session comments, pushes a branch or opens a pull request, it does so as the magpie, with a bot badge, so everyone can tell who said what.

Comments

Talks on issues and PRs in its own voice.

Pushes branches

Commits authored by muse-corva[bot].

Opens pull requests

Proposes changes and waits for Loren.

Won't merge or approve

Merging to main stays Loren's call.

Won't fake CI

No checks/statuses permission. CI speaks for itself.

No admin

Can't change repo settings or delete anything.

HOW IT WORKS

  1. Registered once from Loren's machine. The private key lives in the macOS keychain, never in the repo.
  2. On demand, a script signs a short JWT and trades it for a one-hour token for one repo.
  3. Every Claude Code session starts with small gh and git wrappers that use that token.
  4. On GitHub it's muse-corva[bot]. Where the app isn't installed, the wrappers fall back to Loren, and say so.

THE MAGPIE

Active, inquisitive, collecting. It goes and looks, brings back what it found, and says what it did in its own name. The visor is the mask; the orange glory behind it is a nod to where its voice comes from.

The logo began as the orange identicon GitHub generated for the bot, a happy accident that already looked like a bird under an orange sky. It's evolving toward the full magpie one notch at a time.
