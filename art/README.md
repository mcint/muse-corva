# art

`uv run art/corva.py` → `out/<variant>.png` (512px), `out/<variant>-32.png`
(favicon size), `out/sheet.png`.

| variant | what |
|---|---|
| `glory-eyes-night` | **pick**: crown-fan glory + light from behind the mask |
| `glory-night` | glory, dark mask |
| `eyes-night` / `eyes-dawn` | mask glowing, faint rays above |
| `full-night` / `song-night` | + light from the open beak (weakest, iterate) |
| `*-dawn` | light background |

GitHub has no API for app logos: upload by hand at
https://github.com/settings/apps/muse-corva → Display information.
