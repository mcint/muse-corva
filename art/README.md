# art

`uv run art/corva.py` → `out/<variant>.png` (512px), `out/<variant>-32.png`
(favicon size), `out/sheet.png`.

| variant | what |
|---|---|
| `glory-eyes-night` | **pick**: crown-fan glory + light from behind the mask |
| `glory-night` | glory, dark mask |
| `eyes-night` / `eyes-dawn` | mask glowing, faint rays above |
| `full-night` / `song-night` | + light from the open beak (weakest, iterate) |
| `*-dawn` | light background |

`default-avatar.svg` (+ `.png` render): GitHub's default identicon for
`muse-corva[bot]`, `#e36209` on `#ffebda`. Saved from MC's download.

## Transition (identicon → glory, 10% notches)
`uv run art/transition.py` → `transition/{emerge,dissolve,fade}-00..10.png`
(512px) + `*-sheet.png`. Step 00 = identicon, step 10 = `glory-eyes-night`.

| style | how |
|---|---|
| `emerge` | visor first at 10%, then rays, then bird, dissolving in pixel by pixel; identicon sky fades to night |
| `dissolve` (**MC's pick**) | every pixel flips by rank (visor, rays, bird, sky); whole-bird outline already at 10%, figure/ground flips around 30% |
| `fade` | identicon as a transparent overlay, alpha 1 − k/10 |

**Current logo: `dissolve-01`** (uploaded 2026-11-18, badge background `#ffebda`).
Next: `dissolve-02` … `-10`, one notch at a time. Around 06–07 switch the
badge background to night `#12131a`.

GitHub has no API for app logos: upload by hand at
https://github.com/settings/apps/muse-corva → Display information.
