# Spec: activity

## Want
"What just happened in this repo?" and "tell me when the next push lands",
from the terminal, composable with `pages-wait` and friends.

## CLI
```
scripts/activity [--repo o/r] [--ref BRANCH] [--limit 10] [--json]
                 [--follow [--count N] [--interval 10] [--max-interval 120] [--timeout S]]
```
- Source: `GET /repos/{o}/{r}/activity?per_page=..[&ref=..]` (newest first;
  printed oldest first).
- Line: `2026-11-19 07:33:44  pr_merge        gh-pages  8919a08→b654ca5  mcint`.
- `--follow`: print the last `--limit` (0 = none), then poll; print events
  whose id wasn't seen. Interval starts at `--interval`, doubles on each
  empty poll up to `--max-interval`, resets on new events.
- `--count N` (with --follow): exit 0 after N new events. `--timeout`: exit
  2 when reached. Ctrl-C exits 130 quietly.
- `--json`: one JSON object per line, the API's fields as-is.

## Tests (`tests/test_activity.py`, fake API + clock)
oldest-first order and limit; ref passed through; JSONL; follow prints
only new ids; backoff doubles to the cap and resets on activity; --count
stops; --timeout → 2.
